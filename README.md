# Pathogenic Mods

## ChooseAll
**Version:** 1.0.0

中文：  
“我全都要！”  
在道具选项前（包括道具奖励房和Boss奖励），你可以拿走所有道具。  
在升级（非改变形态）时，你可以自由选择0-4个项目，而不是必须4选1。  
  
—  
  
English:  
"I want them all!"  
In item choices (including free body part rooms and boss rewards), you can take ALL of them.  
In level-ups (no shape changing), you can choose 0-4 items at will, instead of forced choosing 1 from 4.
